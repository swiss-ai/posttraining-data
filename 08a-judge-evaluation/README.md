
## Judges

The job of the judge is to rank responses to a prompt. The choices to be made for each judge include:

- Model
- System prompt
    - Aspect
    - Scoring range
        - 1 to 5
        - 0 to 9
    - Reference answer
        - Self-generated
        - Provided
- Number of responses per call
    - 1
    - 2
    - Many
- Scoring method
    - Expected logprob
    - Average over multiple scores
